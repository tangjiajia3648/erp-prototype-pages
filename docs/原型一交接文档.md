## 4. 最重要的已确认业务规则

### 4.0 2026-09-04后续确认（优先于下文旧状态）

- 预提价保、奖励是供应商给我们的预计收益，计算预计毛利时加上，不扣减，也不等同实际到账。
- 当前原型价保奖励按 Σ［采购数量 ×（预提单台价保 + 预提单台奖励）］动态计算，数量暂沿用原有采购数量口径。毛利 = 销售收入 − 采购成本 + 价保奖励，毛利率联动；收入为0时毛利率显示“—”。
- 库存商品、毛利回补、含税口径、月均毛利率仍待确认。当前未计库存成本及毛利回补；月均毛利率已移除固定演示值，显示“—”，提示规则待确认。
- 预算详情不显示变更记录；仅隐藏展示，未删除底层历史数据能力。预算列表未在此次范围内。
- 预算详情关联单据不展示合同页签及订单表中的合同相关字段。
- 预算只读页面展示4个演示附件，长文件名可换行；预览、下载仅提示演示用途。
- 新建/编辑预算相邻模块保持16px间隙，正文底色与右侧工作台统一为浅灰蓝（#eef1f5），卡片保持白色。

### 4.1 预算与订单：单向复制，不回写

正确关系：`预算内容 → 复制到订单 → 订单独立调整`。

- 销售订单、采购订单可以自动带出关联预算内容。
- 用户可以基于带出内容调整当前订单。
- 订单修改绝不反向修改原预算单。
- 已保存订单使用当时的数据快照，不随预算后续变化自动覆盖。
- 保留关联预算编号以追溯来源。
- 销售订单修改不需要单独展示修改记录。
- 预算自身是否展示修改记录仍然待定；不能因为订单修改而新增预算修改记录。

禁止恢复的旧理解：订单提交时回写预算、订单编辑产生预算变更记录、输入订单字段直接更新预算。

### 4.2 关联预算与合同

- 新建/编辑的关联预算单、关联合同采用输入框形式，支持上游自动带出。
- 按创建方式控制显示和是否可选择，不为尚未生成的合同虚构编号。
- 通过合同创建：关联合同，预算可由合同带出。
- 通过预算创建、后补合同：关联预算，说明合同待补充。
- 联合审核或先合同后订单：展示合同处理说明及适用的合同信息区域。
- 无需合同：不要求关联合同。
- 更换来源单据时，如会覆盖当前订单调整，应先提示确认。
- 采购订单不增加“关联销售订单”字段；当前原型已经移除该字段及相应示例属性。

### 4.3 业务类型与销售订单创建方式

| 业务类型 | 已整理的创建方式 |
|---|---|
| 产品导向分销 | 合同和订单一起审核；先提交订单后补合同；先提交合同、订单暂存草稿；通过合同新建订单 |
| 订单导向分销 | 通过合同新建订单；通过预算新建订单、后补合同 |
| FA-以销定采 | 仅审核订单、无需合同；通过合同新建订单 |
| FA-囤货分销 | 合同和订单一起审核；先提交订单后补合同；先提交合同、订单暂存草稿；通过合同新建订单 |
| 项目A类 | 通过合同新建订单；通过预算新建订单、后补合同 |
| 项目B类 | 通过合同新建订单；通过预算新建订单、后补合同 |

代码中存在历史名称：`FA囤货`、`囤货分销`、`FA-囤货分销`，以及 `项目A`、`项目A类`、`A类` 等。做联动时应检查现有归一化逻辑，不能仅更改显示名称导致规则失配。

### 4.4 本轮不扩展的影响范围

- “是否属于项目后运行单”：保留适用字段，不分析或扩展后续影响。
- “华为报量”：不扩展后续影响规则。
- 自动生成对账单、自动生成付款草稿统一默认；当前实现两者默认开启。
- 销售订单的自动生成收款通知当前默认开启。
- 系统生成合同仍支持人工上传附件，暂不区分系统版、签署版等附件类型。

## 5. 页面和交互最终口径

### 5.1 所有预算、合同、订单的模块导航

- 只显示序号、模块名称和当前定位。
- 不显示“待完善、已完成、已填写”等模块状态或数量标签。
- 必填校验可以在提交时提示，不以导航状态代替。
- 不删除真正的单据状态、审批状态。

### 5.2 预算详情与审批

- 标题摘要视觉与采购合同详情/审批母版一致。
- 当前摘要包含预计销售收入、预计毛利、预期毛利率、低流速商品种类数。
- 不显示右上业务操作；预算详情不提供编辑、提交等业务操作。
- 审批页保留底部审批操作；详情不提供评论回复操作。
- 供应商/客户查看和附件预览属于只读查看，应保留。
- 预算自身修改记录是否展示仍待定，本轮不擅自删除原有数据能力。

### 5.3 低流速商品统计

- 按SKU种类去重统计，同一SKU多行只计一次，不按商品件数累计。
- 显示“低流速商品：N种”。
- 零时显示“0种”，不风险高亮。
- 当前代码通过商品 `lowFlow === true` 标记判断，按 `skuCode` 去重；示例商品中有标记。
- 低流速业务判定阈值没有确认，不得自行根据销售周期或库存天数推断。
- 缺少SKU标识的数据如何计数仍需在真实数据接入时确定，不能把名称当成可靠SKU标识。

### 5.4 预算状态提醒

- 新增/编辑：根据实际填写问题显示，比如未选供应商、商品为空。
- 详情：显示实际业务风险，不出现“请填写”等编辑提示。
- 审批：显示审批需关注的事项，例如低流速商品的采购数量和销售计划。
- 无提醒时隐藏，数量动态计算，不固定写“2项”。
- 当前只实现已具备数据依据的提醒；不虚构毛利、账期风险阈值。

### 5.5 销售订单

- 详情、审核需要标题摘要，重点突出订单金额和账期。
- 详情不需要右侧实时工作台。
- 收货与交付、收款与开票保持统一网格，字段标签在上、内容在下。
- 附件与说明纵向排列：备注、上传区、附件列表，不强行左右拼接。
- 商品明细保留数量、价格、库存、交货单、出库等业务字段及商品辅助查看入口。

### 5.6 采购订单

- 不展示关联销售订单。
- 到货与结算、付款与结算采用整齐网格。
- 附件与说明采用与销售订单一致的纵向布局。

### 5.7 供应商与客户详情抽屉

- 点击名称，从右侧打开只读详情，不新建系统顶部任务页签。
- 长名称、地址允许换行；资信宽表在表格内部横向滚动。
- 空业务数据展示“—”，金额示例目前使用“0.00”，并明确标注演示数据。

供应商字段：

- 名称、工商名称、统一社会信用代码、法定代表人、省市区、详细地址、业务员、创建时间、标签。
- 采购在途数量/金额。
- 预付金额、应付金额、应收发票、供应商价保、供应商待结算价保、可用折扣、应收价保、应收奖励。

客户字段：

- 基础信息同上，增加华为省代CBG Code、华为KA客户编码、销售在途数量/金额。
- 预收金额、应收金额、应付发票、客户价保、客户已用折扣、客户待结算价保。
- 资信数据：公司名称、信用等级、注册/实缴资本、成立日期、法定代表人、上年度参保人数、关联往来单位、授信额度、本次申请额度、当前额度占用、当前超期应收、最长超期天数、关联企业额度占用/超期应收、应收/预收余额、应付、预付、当前可用额度、现款占用、账期占用。
- 月度指标：提货次数、提货金额、账期提货金额/占比、超期订单平均天数、最长超期天数/金额、超期次数/总提货次数、超期金额/总提货金额。
