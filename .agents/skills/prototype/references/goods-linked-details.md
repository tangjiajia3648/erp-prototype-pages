# 采销明细关联详情

- 库存详情按商品、库存主体和仓库维度展示；保留SPU名称、SKU名称、库存数量、配置说明、仓库名称和数量。
- 单品详情按采购、入库和序列号维度展示；保留采购日期、采购人、采购责任人、入库日期、仓库名称、序列号、更新序列号、采购对账状态、开箱状态、开箱说明、发票和采购说明。
- 两类详情只在用户点击时生成动态页签：库存数量进入库存详情，采购、销售或商品数量进入单品详情。
- 同一种详情默认只保留一个页签；查看另一商品时复用并更新内容，避免大量页签。
- 动态详情留在当前单据的商品明细模块内，不进入系统顶部任务页签或右侧模块导航。
- 没有SKU编码时不虚构编码。页签使用详情类型加截断后的SKU名称或SPU名称，悬停展示完整名称，内容顶部展示完整商品识别信息。
- 编辑态保留数量输入并提供轻量查看入口；只读态使用可点击的蓝色数量。
- 预算、采购／销售合同、采购／销售订单的新建、编辑、详情和审批页面共用同一规则，不改变现有库存明细和单品明细字段逻辑。
